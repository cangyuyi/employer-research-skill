# 证据、薪酬与算式检查

## 证据应支持什么，而不是“看起来权威”

| 材料 | 可以支持 | 不应直接推出 |
| --- | --- | --- |
| 法定报告／交易所公告 | 披露主体、报告期、所披露指标 | 未来工资稳定、企业不会裁员 |
| 企业官网／ESG／招聘原文 | 企业公开倡导、制度陈述、发布过的条件 | 每个部门真实体验、人人享有所有福利 |
| 高校就业平台 | 该页面所刊载的岗位与字段 | 平台担保待遇、岗位当前有名额 |
| 政府政策 | 目标、规划与政策方向 | 目标已实现、指定企业会扩招 |
| 学生或员工个案 | 这个人的公开经历 | 全体员工平均情况、普遍录用概率 |
| 媒体与聚合页 | 提供线索、补充上下文 | 无原始出处的金额与招聘要求已证实 |

多个转载页面可能同源。先找原始披露，再用真正独立的材料检验冲突。源头仍是企业自报时，应一直保留这个属性。

## 每项重要信息的最小记录

来源：稳定ID、标题、发布者、类型、发布日期或“未确认”、查阅日期、原始URL、定位、适用范围与局限。需要留档时加本地路径和哈希。

主张：陈述内容、事实／分析／建议、对应来源、页码／章节／字段、核验状态，以及会影响使用的限制。“金额字段已抄对”与“实际收入已核实”应分开。另记录原文是否完整取得；页面／表格图像与文本是否核对；报告是否经审计，不能把转载页面的权威感当作审计属性。

岗位：页面职位原名、岗位所属主体、地区、招聘时间及状态、专业栏与正文要求、原始薪资、明确和缺失的计薪条件、职责事实、分析建议。若没有找到可靠报价，写“未取得可核对的单岗薪酬”，不借其他岗位或企业整体宣传补齐。

ID是引用键，不是排序号。删去错误来源后不必补齐连续编号；若改号，必须同步更新正文、索引、存档映射与PDF链接。不要让最终S03指向早期采集时同名但无关的网页。

## 在线与存档检查

1. 检查标题和正文中的主体、岗位、期间，而不只查HTTP状态。200也可能是“招聘过期”提示或另一家公司的公告。
2. 搜索不到原链接时，回到企业列表、招聘目录、公告目录，而不是尝试相邻编号。
3. 大文件优先看已有原档与引用页面；有必要才重新下载。HEAD只能说明这次链接响应，不能证明内容未改。
4. 动态浏览计数或站点导航更新可能改变HTML哈希；对相关正文作语义比较，避免把哈希变化写成数据变化。
5. PDF表格提取可能错列、漏负号或混入页眉。金额、年份和对应列应结合页面图像检查。OCR结果不作无需人工确认的定论。
6. 本次可访问、公开发布、内容匹配、招聘有效、待遇兑现是五件不同的事。
7. 下载后检查PDF文件头、解析页数及关键页；截断响应或扫描版空文本不能冒充完整正文。若出现大小上限，明确下载不完整，不将截断文件以正常PDF交付。
8. 对公开页面的嵌入HTML、压缩文本或客户端数据，可按该页面公开展示逻辑还原并记录过程。只处理原本公开的内容；遇登录、付费、验证码、环境校验或脱敏即保留限制，不尝试绕过。
9. 当前动态分页与搜索旧摘要不一致时，寻找稳定文章／职位链接；找不到则降级。邻接日期、薪资和推荐职位不能自动归属于目标条目；不得补出精确发布日期。

## 薪酬决策表

| 现有证据 | 允许写法 | 不允许的补全 |
| --- | --- | --- |
| 仅写“20000元以上” | 页面原字段为20000元以上，周期待确认 | 保底月薪2万、年薪24万 |
| 人才计划上限 | 某计划在特定阶段的宣传待遇 | 所有应届生起薪 |
| 企业年平均工资 | 企业自报的整体历史统计 | 本科某岗平均收入或中位数 |
| 历史招聘 | 某时间和地区曾发布的条件 | 目前在招、现行标准 |
| 某岗包住宿／股票激励 | 该岗位原文条件及适用范围 | 公司所有岗位人人享有 |
| 表格与正文专业条件不同 | 指出差异，请招聘方明确 | 自动选择“专业不限”一边 |

不将公开招聘字段混成市场薪酬样本；不得以岗位均值、箱线图等方式制造不存在的统计代表性。

## 指标与成果的适用边界

- 原始值、单位、对应列和合并范围先匹配，再用Decimal复算；提供的算式自洽不代表原文已核实。
- 年报与半年报分别标报告期间及审计属性；不能用全年金额作半年同比基数。负基期或零基期不机械套通常同比公式。
- 员工总数注明母公司／合并范围；技术人员不是研发人员，资本支出也不是研发费用。
- 专利申请、授权与有效量不同；论文作者单位、共同完成、企业独立完成和商业化分别取证，不能凭题名补机构。
- 行业样本数量、采集框和选择偏差未明确时，不声称市场均值、中位数或就业率；企业A与B不能只取宣传上限排名。

金额算式和薪酬字段见[evidence-schema.md](evidence-schema.md)。
