# 研究与证据协议

按需阅读：主体与日期；来源发现；断言记录；数据冲突；结构化输入。适用于完整调查或复核，不要求简短问答建立所有工件。

## 主体与时间

先记录公司原名、用户称谓、官方域名、地区与要研究的岗位／专业。名称有歧义时用业务、地点和域名消歧；不能由品牌推断实际雇主。

至少保留能影响结论的日期，不用一个“时间”字段覆盖一切：

| 字段 | 问题 |
|---|---|
| 访问日 | 这次实际何时查看？不冒充页面更新日 |
| 发布日 | 材料何时公开？未标日期不根据抓取时间补写 |
| 数据截止日 | 人数、专利、业务指标统计到哪天？ |
| 活动日 | 宣讲／报名／面试何时发生？未来活动不等于未来发布 |
| 届别 | 面向哪年毕业生？不等于招聘年份或当前空缺 |
| 复核日与版本 | 更新既有报告时，新资料是否晚于原调查日？ |

如果月份、日期不可知，保留原有精度，例如2026年、2026-09，不补成虚假的具体日。

## 来源发现与阅读

按照断言选择来源，不能只有抽象的权威排名：

- 主体登记信息需要对应登记资料；高校企业简介只能证明其页面这样标注。
- 岗位要求、广告报价优先读企业招聘页、企业发布在高校的正文及原附件。
- 公司文化与培养机制优先企业原文，但仍标企业自述。
- 学术成果使用原论文或可见的论文元数据，核对题名、DOI、日期和作者单位；只读摘要／元数据就不描述未读全文的技术细节。
- 行业趋势使用政府原始政策、研究原文等，避免由行业政策直接推断单家公司扩招。
- 招聘聚合页、搜索摘要、匿名评价只作线索，或以明确的有限证据身份出现。

打开附件前后都看文件名。学校、地区、岗位序列、版本、资格等限定可能只出现在附件名、表头或脚注。截图／图片中的表格要实际查看，不能用网页周边文字代替。

原文件保持不变；必要时另存提取文本、访问记录和校验值。别为了保存出处无选择地批量下载整站或无关个人资料。

失败来源：先找同主体原站、同份原文件或可靠直接发布页；少量替代尝试仍失败，记录访问受限。不要不断重试、以摘要替正文，或将镜像改称独立交叉验证。

## 来源与断言分离

来源表记录“读了什么”；断言表记录“据此要说什么”。一个来源可以支撑多条断言，一条断言也可能受到多来源冲突。

最小字段建议：

- 来源：`id / title / publisher / location / accessed_at / published_at / data_as_of / status / kind / scope / original_filename / locator`。
- 断言：`id / text / type / source_ids / status / qualifiers / remaining_questions`。
- 职业：`id / title / source_ids / sample_status / current_vacancy_confirmed / qualifications / compensation / relevance`。

`locator`应指向实际支撑该断言的页码、段落、表格行、附件节或网页字段，而非仅贴首页地址。大量断言时可放在各断言内。

推荐显示标签：

| 标签 | 解释 |
|---|---|
| 公开记录 | 能核对对应记录内容；证明范围不超出该记录 |
| 企业自述 | 文化、人数、专利、培训等由企业供稿或陈述 |
| 调查分析 | 对专业匹配、进入决策或发展路径的推论 |
| 访谈陈述 | 有实际访谈及约定引用范围，不代表全公司情况 |
| 未核实／来源冲突 | 缺证据、适用范围不清或记载不一致 |

不要把“网页可读”“结构校验通过”“多个域名重复同稿”写成数据已独立验证。

## 冲突处理

先检查时点、主体、地区、职业层级、计数单位、资格版本和数据口径，只有证据明确证明可比才合并。

- 不能解释时并列：来源、统计时点、原数值、范围限制、剩余问题。
- 不自动选最大或最新发布页；新发布页可能沿用旧文案。
- 比例和增长率只有分子分母、边界与日期一致且有必要时才计算，并标公式。
- 没有解释不等于公司造假；也不能编出“这是不同学校待遇”等确定原因。

## 统一格式与来源状态

统一字段及迁移见[evidence-schema.md](evidence-schema.md)。read表示作者实际读到对应正文；snippet_only、inaccessible、excluded和unconfirmed不能被脚本升级为已读支持。即使read，也不代表内容经独立证实。supported或historical的事实必须有关联的已读支持；conflicting需至少两份已读记录，但是否真正独立仍靠语义审校。

## 下载与读取

检查文件头、解析页数和对应页内容。扫描PDF的空提取文本不等于不存在制度；大文件截断必须标为不完整。处理公开网页的内嵌正文只限正常公开展示内容，不访问未授权身份信息或绕过访问校验。
